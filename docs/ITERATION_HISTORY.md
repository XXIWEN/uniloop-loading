# 设计与迭代记录

本文整理本次 UniLoop 加载页从视觉方向到可交付实现的主要决策，方便后续开发者理解为什么页面采用现在的结构。

## 目标

将 UniLoop 的加载状态设计成一个有品牌识别、体现跨校连接、且能显示真实加载进度的轻量全屏动画。五校节点为 University of Sydney、UNSW、UTS、Western Sydney University、Macquarie University。

## 需求演变

1. **建立品牌场景**：以 UniLoop Logo 为视觉中心，加入悉尼歌剧院背景剪影和五校校徽，校徽只保留图形标识（后来针对 WSU 特别要求保留其官方校徽组合中的英文名称）。
2. **校徽环绕中心运动**：先后澄清校徽应像摩天轮一样各自沿环轨移动，而不是只在原地自转；圆心应与 UniLoop 标识对齐，五个节点大小也需更协调。
3. **表现跨校联结**：从随机散发线条改为五个大学节点明确连成五角星，让连接关系一眼可读。尖锐星角调整为圆润连接，动画放慢，逐步建立连线。
4. **加入进度反馈**：加载条和百分比需要由宿主页面的实际加载进度驱动，不能只靠三个跳动的装饰球，也不能永远显示静态 0% 或假装已完成。
5. **兼顾快加载与慢加载**：真实页面可能很快完成，因此增加最短展示时间，避免动画闪屏；真实加载较慢时继续按实际进度运行，并保留超时兜底。
6. **排除不合适方向**：移除曾讨论过的额外小球物理链式动画；连接主体回到五校徽章和五角星。保留歌剧院剪影，不采用复杂、花哨背景装饰。
7. **校徽修订**：USYD、UNSW、UTS、Macquarie、WSU 的节点造型经过尺寸及裁切调整。WSU 节点使用提供的完整校徽组合，保留盾牌与“WESTERN SYDNEY UNIVERSITY”字样，不在图标下重复添加额外标签。

## 最终动效结构

### 旋转轨道

五个 badge 元素固定在同一圆形轨道半径上，轨道本身以 CSS 变换绕场景中心旋转。徽章图片通过反向角度补偿保持正立。旋转周期为 24 秒一周，速度较慢，避免转盘感过强。

### 五角星连接

Canvas 根据旋转后的节点坐标重算五角星。节点按以下次序连接：

```text
Macquarie → UNSW → Western Sydney → University of Sydney → UTS → Macquarie
```

路径以二次曲线采样处理圆角。底层显示低对比度完整路径，前景线段长度跟随加载进度逐步增长。每 20% 进度点亮下一所学校节点。

### 中心与背景

- 中心 UniLoop Logo 呼吸式轻微缩放，并带淡色光晕。
- 地球内部线条做极慢的微幅旋转。
- 悉尼歌剧院以低透明度剪影呈现在背景，不遮挡 Logo 与进度条。
- 底部浅灰波浪保留为轻量装饰。

### 加载进度与收尾

- 宿主可调用 `window.setUniLoopLoadingProgress(percent)` 或发送 `uniloop:loading-progress` 自定义事件。
- 外部进度启用后，独立演示进度会停止。
- 进度到 100 且校徽资源完成加载后开始淡出；最短显示时长约 1.4 秒，结束缓冲 450ms。
- 10 秒超时自动淡出，避免异常时遮罩长期阻塞页面。

## 重要实现约束

- 旋转位移都相对同一个中心与统一半径计算，避免用 margin/偏移量逐个“凑”位置。
- 不让校徽因轨道旋转而倾斜；节点图片角度抵消轨道角度。
- 不生成额外的物理小球；动态连接以五角星路径绘制。
- 动画使用原生 CSS、Canvas、JavaScript 和 `requestAnimationFrame`，没有第三方依赖。
- 支持 `prefers-reduced-motion`，减弱动态效果。

## 后续可改进项

- 在宿主网站接入真实资源/路由加载进度，并以实际浏览器环境核对进度展示。
- 由设计或品牌负责人确认所有校徽素材及公开使用许可。
- 如需更严格的无障碍支持，可加入可配置的状态文案和可关闭的动画选项。
